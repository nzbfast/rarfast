# A member whose name reads empty, under each read command (11 Oct 2026)

`empty-name-commands-probe.py`, the 25 archives and the table here are
behind SPEC-CLI 2.1 M18. The probe BUILDS the archives byte by byte by
the layouts SPEC-F states (14 of the older container, 11 of RAR 5;
they are the same bytes on every run and every system) and puts each
to the programs with `t`, `x`, `e`, `p`, `l`, `lt` and `lb`, `x` and
`e` with a destination given, with none, and with one that is not
there. Its docstring says
what a row holds.

`empty-name-commands-7.23-macos-arm64.tsv`: 550 rows, unrar 7.23 and
rar 7.23 for macOS on arm64 (SHA-256 `99720d63484b8db7` and
`fd6c7db73c659a28`, first 16), the two the same in every row. Of what
the programs printed only counts and the keys of the probe's marker
phrases are kept.

`empty-name-commands-7.23-linux-x86-64.tsv`: the same probe and the
same 25 archives on 11 Oct 2026 with unrar 7.23 and rar 7.23 for
x86-64 Linux (SHA-256 `926d3a00775ed96a` and `56c3c4fd46faa7a9`, first
16; an AMD EPYC 4345P, as root). 22 archives answer as on macOS; the
three named by the bytes `E9 E8` are members with a name there.
